# FileKeeper
 This project main purpose is keeping important files of different machines up to date, allowing loading, unloading and comparing, based on the user's configuration.

 **NO**, I won't use NixOS.

![Mental Image](docs/MentalImage.png)

# Configuration
FileKeeper uses a TOML configuration file for quick and easy setups. A default template is generated by running FileKeeper for the first time.

The configuration file is the `config.toml` at the base config folder ("~/.config/filekeeper/" on Linux and "%appdata%/FileKeeper/FileKeeper/" on Windows), it can also be edited by running:
```fish
fkp edit
```

An example of a valid config is:
```toml
[group."general"]
repository = "/home/user/keep1"
entries = [
"/home/user/entry_x/",
"/home/user/entry_y/",
"/home/user/entry_z.toml",
]

[group."machine 1"]
repository = "/home/user/keep2"
entries = [
"/home/user/entry_1.lua",
"/home/user/entry_2/",
"/home/user/entry_3/",
]

[group."machine 2"]
repository = "/home/user/keep3"
entries = [
"/home/user/entry_a.sh",
"/home/user/entry_b/",
"/home/user/entry_c",
]
```

The group "general" will always be used, if defined, meaning FileKeeper will consider both the general and selected group's repositories and entries.

You can change the current group by changing the file `group_name.txt` also at the base config folder, or by running:
```fish
fkp switch [GROUP]
```
